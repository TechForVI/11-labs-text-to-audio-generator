What's New in 11 Labs Text to Audio Generator 3.0
​We are pleased to announce the release of version 3.0 of the 11 Labs Text to Audio Generator. This update focuses on performance optimization, transparency, and expanded generation capabilities to provide a seamless user experience.
​Instant Execution
The extension has been completely optimized for speed. It now executes and launches instantly without any loading delays, allowing you to start generating audio immediately.
​Real-Time Token Usage Display
You can now monitor your API quota effortlessly. Whenever you generate an audio file, the extension will instantly display the exact number of tokens consumed for that specific prompt right on the main screen.
​Expanded Model Selection
We have introduced more versatility to your audio generation. By navigating to the Settings menu, you will now find an option to choose between two distinct AI models, including the newly added Multilingual model, ensuring better language support and voice accuracy.
